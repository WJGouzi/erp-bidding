# 规格：表格定位 (table-positioning)

## 概述

在标书生成阶段，确保表格在生成的 DOCX 文档中出现在正确的章节位置——紧跟在对应章节标题和段落文本之后，而不是堆在文档末尾。

## 功能需求

### FR-1: 表格按章节顺序渲染

- 生成的标书文档中，表格必须出现在其所归属章节的标题和段落文本之后
- 多个表格在一个章节中按原始文档的出场顺序排列
- 表格与文字段落交替时，顺序与原始文档一致

### FR-2: 跨章节定位正确

- 第一章节的表格出现在第一章节内部
- 第二章节的表格出现在第二章节内部（在第一章节内容之后）
- 表格不会"穿透"到后续章节或堆叠到文档末尾

### FR-3: _last_element 追踪正确

- `_write_outline_item` 中使用的 `_last_element` 引用必须在所有递归层级中正确传递
- 子章节的内容插入到父章节最后一个内容元素之后
- 每个内容块（段落、表格）写入后必须更新追踪引用

## 非功能需求

### NFR-1: 文档结构完整性

- 表格插入不破坏 body 元素的 XML 树结构
- 表格前后的段落不丢失
- 合并单元格在生成的文档中正确渲染

### NFR-2: 兼容性

- 支持 ContentBlock 渲染路径和 JSON table marker 路径两种写入方式
- 两种路径都使用相同的定位机制
