## Decisions

### 1. tblpX 值计算

**决策：基于 640 twip 从页面右侧推算 tblpX 值**

在 OOXML 中，`tblpX` 定义的是表格左边缘到页面左边缘的距离（当 `horzAnchor="page"` 时），而非直接支持"距离右边 X"。因此需要通过换算得到左边缘值：

- 页面宽度 = 21 cm（A4 标准）= 11906.25 twip ≈ 11906 twip
- 表格宽度 = 3 cm = 1701 twip（当前列宽设置）
- 右边缘位置（距左）= 11906 - 640 = 11266 twip
- tblpX（左边缘距左）= 11266 - 1701 = **9565 twip**
- 换算为 EMU：9565 × 635 = **6,073,775 EMU**

**备选方案考虑：**
- 方案 A（选中）：硬编码 6073775 EMU，简单直接，与现有风格一致
- 方案 B：通过 `document.sections[0].page.width` 动态计算，更通用但增加了实现复杂度，当前所有封面均使用 A4 页面，无实际收益

### 2. tblpY 值确认

用户指定 tblpY = 640 twip，换算为 EMU：640 × 635 = **406400 EMU**。当前代码已使用此值，**无需修改**。

### 3. 垂直居中实现

**决策：在每处"正本"表格单元格上设置垂直居中**

在现有代码基础上，在设置完 `_zhengben_cell.text = ""` 之后，添加垂直居中设置：

```python
# 设置单元格垂直居中
_tc_pr = _zhengben_cell._tc.get_or_add_tcPr()
_v_align = OxmlElement("w:vAlign")
_v_align.set(qn("w:val"), "center")
_tc_pr.append(_v_align)
```

说明：
- `w:vAlign` 是 OOXML 表格单元格级别的垂直对齐属性，`val="center"` 表示垂直居中
- 该方法与 python-docx 的 XML 操作风格一致，兼容现有代码

## Risks / Trade-offs

- [低] 硬编码 tblpX 值假设 A4 页面宽度为 21cm。如果未来使用其他页面尺寸（如 A3、Letter），右侧距离会偏移。可通过改用动态计算来规避，但当前无此需求。
- [低] 三处重复代码在后续修改时需同步更新三处。如未来继续调整"正本"样式，建议提取为公用函数。
